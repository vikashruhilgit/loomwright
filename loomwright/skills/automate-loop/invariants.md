- **`review-heal` / `/review-pr` / Supervisor Phase 4.5 still NEVER merge.** They terminate at `PASS` / `READY` / `ESCALATED` and leave the PR open. The **invariant — the ONLY place in the plugin that EXECUTES `gh pr merge --squash` is this `automate-loop` `--auto-merge` gate, implemented in `automate-helpers.sh gate-eval`** (§10) — holds regardless of how many docs *describe* it.   - `skills/automate-loop/SKILL.md` — this contract (§10/§11).

- **All `/autonomous` correctness gates bubble up** — NO-GO, Plan Review FAIL×3, Supervisor adjudication, the rubric gate — exactly as they do for a direct `/autonomous` run. The engine never auto-picks an adjudication option. With fresh phase sessions (the default; automate-speed/09) the same gates are asked inside the Launch Pad or Supervisor phase session and reach the owner through the relay — the session defers, the coordinator re-asks the recorded question verbatim and `phase-answer` resumes it; the coordinator never answers one itself, and a gate that cannot be asked keeps its named can't-ask status (`docs/ARCHITECTURE_CONTRACTS.md` §"Question-gate inventory", context HR).
- **`--notify` / `--non-interactive-fallback` / `--cheap` pass through** to the inner `/autonomous` invocation (forwarded on the RUN step). `--non-interactive-fallback` also governs the engine's own gates (queue-confirm skipped, ambiguous resume fails closed, one incomplete run without `--resume` fails closed `resume_requires_flag_non_interactive`, prompt intake passes `--non-interactive` to `/product-owner` and stops on `po_gate: needs_owner` — §2/§4). `--cheap` is a **pure passthrough** — the engine never interprets it and does NOT persist it in `## Run Config` (like `--notify` / `--non-interactive-fallback`): re-pass it on each `/automate --resume` or `/loop` tick; profile semantics: `docs/ARCHITECTURE_CONTRACTS.md` §"Cost Profiles". **Fresh phases** (no `--inline-phases`): there is no inner `/autonomous` — the driver puts `--non-interactive` on the Launch Pad and Supervisor phase prompts and `--cheap` / `--max-tokens N` on the Supervisor one; `--notify` (`/autonomous`'s gate webhooks) has no fresh-phase consumer and is forwarded only under `--inline-phases`.
- **`.fix_floor` needs no pass-through.** The one fix-time severity threshold (`scripts/fix-floor.sh`, default `MEDIUM`) is read from `.supervisor/config.json` by every step the engine drives — Launch Pad's plan review, Supervisor Phase 4.5, and the owned drain; `config-suppress` merges `auto_review` into the existing object, so the key survives the RUN window, and lane clones copy `config.json` from the primary.
- **Concurrent-run constraint (ENFORCED, red-team-hardening/06):** the `.auto_review:false` window (§7) is **repo-global** while set — two `/automate` loops in one repo would collide on the toggle, `git checkout`, and `state.md`. PICK (§6 step 1) acquires `.supervisor/run.lock` (`scripts/run-lock.sh acquire --owner automate:<run_id> --session-id <session_id>`) before touching anything, and a second `/automate`/`/autonomous`/`/supervisor` run in the SAME checkout is refused with `run_lock_held owner=<label> pid=<pid> age=<s>` — it never proceeds silently. The nested `/autonomous` → `/supervisor` acquires inside this item's RUN share this run's `--session-id` (a fresh phase session carries it as `LOOMWRIGHT_RUN_LOCK_SESSION_ID`, which re-enters on acquire and never matches a release), so they are **re-entrant** (`run_lock_reentrant owner=automate:<run_id> …`, exit 0, owner unchanged) and their own releases are no-ops — this run's CHECK OFF/park release is the one that frees the lock. Liveness and the degraded case: `docs/ARCHITECTURE_CONTRACTS.md` §"Run lock".
- **Lanes (`--parallel N`, §14 — N = 1 single-lane mode runs one lane at a time):** concurrent runs are allowed only as lanes — each a separate clone with its own `.supervisor/` (its own `.auto_review` toggle, run lock and checkout) — while the primary stays locked for the wave (single-lane mode: for the run) by the `automate-lanes:<run_id>` run-lock owner plus `pick-guard` at every sequential PICK (§6 step 1, parks `live_lane`) and every NEW run's start (§4). A plain second `/automate` in the primary is still refused — also after the coordinator's lock was reclaimed.
