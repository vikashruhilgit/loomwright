test-harvest-conventions (c3) no longer fails when the checkout or TMPDIR path contains `--`
The AC9 flag-freeze assertion extracted flags with a bare `grep -o -- '--[a-z][a-z-]*'` over harvester output that echoes absolute paths, so a clean clone under Claude Code's scratchpad (`…-ai-agent-manager--claude-worktrees-<name>/…`) reported `--claude-worktrees-…` as a composed flag and went red. Flags are now read only in flag position (line start, after whitespace, or after a quote) by one `composed_flags` helper that (c2) and its (M3) control share. New (c3r) runs the harvester with `--root` under a `--`-bearing directory and asserts (c3) stays green; (c3q) proves the anchored extractor still reads real and quoted flags and still catches a spliced bogus flag; (M-c3r) proves the old pattern fails the same output.
