lane-status reads a closed-out lane as Done, and /lanes shows waves and folds finished lanes
A lane closed out after its wave merged showed in /lanes as "✕ Pick · removed", step 1 of 7, red, with no branch or PR. Two causes in lane-status. It counted `removed`, the normal last state after fleet-closeout, as trouble. And it read the lane's run file from the clone that lane-remove had just deleted, so the step history came back empty. lane-status now reads a removed lane's run file, Supervisor state and readiness from the newest `salvage/<lane>-removed-*` copy. It falls back to the parent's `fleet closeout: <lane> … done (PR …)` line when that copy is gone. Each lane gets an `outcome` (done, removed, abandoned) and an `ended_at`. A lane removed unfinished now reads as held, not failed; abandoned still reads as trouble. Each wave record gains `lanes` and a `state` (merged once every lane it carries landed, open otherwise). A new `next_wave` lists the live lanes no built wave carries yet. loomwright-lanes 0.4.0 uses these. The wave card lists every wave oldest first ("Wave 1 merged ✓ PR #51", then "Wave 2 in progress · 3 running"). A finished lane folds into one row: its PR, its wave, when it finished and how long it ran. A lane that has stopped working freezes its clock at `ended_at` instead of counting to now. The pane is also redesigned after an Impeccable critique and audit. The step rail is one continuous bar colored by state: the current step is drawn taller, with a single `step 5 of 7 · 47 min · next: Decide` line in place of seven labels. The inbox moves to the top. The Started and Lanes tiles fold into a Run header line. A parked lane reads "parked for wave N" (◆ now only means a question). Item names are short. Show last 20 steps lists every step, so a step's details no longer need hovering. The note field carries a real label, and Send reads dim until it can send. In a narrow pane the lane title keeps its line. Tints and chart colors come from one named table.
