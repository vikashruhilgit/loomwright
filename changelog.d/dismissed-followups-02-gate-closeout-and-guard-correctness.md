Dismissed follow-ups 02: the merge gate, close-out, salvage, guard and CLI-validator findings closed
Each of the owner-deferred review findings bundled in `dismissed-followups/02` now has one disposition, recorded in `docs/evidence/dismissed-followups-02-engine.md`, `docs/evidence/dismissed-followups-02-validators.md` and `docs/evidence/dismissed-followups-02-repo-scripts.md`: fixed with a regression leg that fails on the pre-fix script, or recorded with a one-line reason.
Automate engine: `closeout` refuses a `--session-id` with no value (and `closeout-classify` classifies that refusal as a guard); the close-out sentinel tolerates trailing blanks and the stamped heading is anchored, so `done-ish` no longer reads as done; a close-out whose only change is a trail PR is no longer recorded as "nothing to close out"; the merge watcher reads `state,headRefOid` alone and fetches `statusCheckRollup` only for an armed escalation re-check, so a failing rollup read can no longer hide a merge; `current-escalation` and `current-set` refuse control bytes and a non-hex `--sha`; `gate-eval` no longer parks a clean checkout when `HOME` and `XDG_CONFIG_HOME` are both empty, and parks when `--root` is neither the git toplevel nor beneath it; the automate-loop split test pins `mkdir -p .supervisor/automate` before `pick-guard` on both surfaces; the watcher header names its lock-free progress-append window.
Standalone validators: `ci-slot.sh` rejects a malformed `LOOMWRIGHT_CI_SLOT_POLL`; `wait-for-checks.sh` reads `--bound 08` and `--call-max 08` as decimal; `worktree-salvage.sh --ignored` fails a symlinked entry; `run-lock.sh liveness --pid ''` is a usage error; `prove-rule-check.sh` keeps its scratch dir and proof file out of the repo's working tree; the `guard-finalize-publish.sh` and `host-mode.sh` headers state their honest limits.
Repo scripts: `bump-version.sh` keeps its scratch dirs under the git dir, so backups a SIGKILL leaves behind never show in `git status`, and `--dry-run` reports a capability contract that is already stale (exit 1) instead of claiming a plugin_version-only change; each of the `ci-local.sh` leak gate's `lsof` calls is bounded by `CI_LOCAL_LSOF_BOUND` (default 10 s) and a cut-off read is reported unchecked; the ci.yml token-budget step is named for all three surfaces it gates. The trace-then-decide findings and the `ci-slot.sh` TERM-path finding are fixed or recorded as each evidence file states.
