Vendor-coupling ratchet counts the coupling that locks the plugin in
`scripts/check-vendor-coupling.sh` now reads named token classes from `loomwright/docs/vendor-coupling-manifest.json` (schema 2: install root, subagent orchestration, ask-user, hook protocol, runtime identity, SDK binding, model names) and prints a reference total per class plus a flat total; the gate still hard-codes no token. Overlapping tokens are attributed leftmost-longest in a POSIX-awk pass, so one occurrence counts once, for one class, on BSD and GNU alike. Agent and command files are a new `adapter_frontmatter` class: their YAML frontmatter stays exempt and their bodies are counted; hooks stay whole-file adapter. A new `raise_check` compares allowances with the base manifest (`$VENDOR_COUPLING_BASE`, else `origin/main`, read from the object store) and fails any new or raised allowance whose `allowance_reasons` entry is missing or inherited unchanged; CI fetches main into a dedicated ref and sets `VENDOR_COUPLING_REQUIRE_BASE=1` so the check cannot silently skip there. The manifest is re-baselined by `--print-allowances` with a reason on every raised or new entry; the re-baseline added no reference anywhere (only the manifest's own entry moved afterwards, as its notes were edited). Reasons are compared normalised, so a whitespace-only edit of an old reason never certifies a new raise, and counting LESS now needs a reason too: a path that held an allowance and becomes exempt or leaves the scan, a token dropped from the declared set, or a raised frontmatter bound each needs an added or changed `policy_reasons` entry. The frontmatter exemption is bounded by `max_frontmatter_lines`, past which the file is counted whole, so a YAML block scalar cannot hide a body. Files are enumerated NUL-separated and verbatim, so a non-ASCII or backslash-bearing name is counted instead of silently dropped, a NUL-bearing file is counted rather than skipped as binary, and a listed path that is not a regular file is an error. An unreadable tracked file is now an error rather than a silent zero. Two self-test flakes are fixed at their cause: `test-ci-slot.sh` now reaps the mixed-N waiters it spawns (a mutant-leg waiter outlived its leg and held the mutex the next leg plants), and `test-session-resume.sh` pins distinct log mtimes so `ls -t` cannot pick a different "latest" log in two otherwise identical fixtures.
