Supervisor prompts carry rules, not stories; FINALIZE and the multi-voter stage load only when used
The Supervisor loop's runtime prompts are now limited to instructions and short rules. Those prompts are `agents/supervisor.md`, `commands/supervisor.md`, `skills/self-heal-advisory/SKILL.md` and `skills/async-orchestration/SKILL.md`. Every story, example, troubleshooting entry and history note moved to `loomwright/docs/rationale/supervisor.md`. Every `story` and `rule` row of the `supervisor` loop inventory now has a non-prose home: `global`, `step-scoped`, an enforcing script, or a rationale heading.
The FINALIZE procedure and the PR Body Template moved to `skills/async-orchestration/finalize.md`. The Supervisor reads that file only at Phase 4 entry, so Phase 2 PLAN and every Execute Manager spawn now load the shorter `SKILL.md` alone.
Phase 4.5's protocol is split by when each part runs. `on-entry.md` covers phase entry and the first-iteration enrichments, `escalation.md` covers base-mismatch cleanup and fix-task crashes, `completion-tail.md` covers the post-loop tail, and `multi-voter.md` is read only when `--multi-voter-heal` is on. `SKILL.md` keeps what every review-and-fix iteration runs, a `# Part 2` stub, and a one-line pointer for each moved heading, so existing section citations and the next-step driver's instruction strings still resolve. `test-loop-inventory.sh` lists the new files as group sources. Tests whose pinned text moved now read it from the split file, with each needle unchanged byte for byte. The pinned citations in `reconcile-resume-state.sh` were re-derived. `check-contract-parity.sh` gained enum rows for the split files that carry status literals.
No rule's condition or action changed.
The size target was only partly met. Counting every split file, the all-modes read set is 26.0% smaller and the default path (no `--multi-voter-heal`, no escalation) is 29.5% smaller, against a 30% goal. The remaining text is either pinned byte for byte by tests or passed verbatim to spawned agents. History references in these prompts are fewer than before. Before/after sizes, history-reference counts, the by-home table, gate results and mutation controls are in `docs/evidence/as15-diet-supervisor.md`.
