Launch Pad phase lines come from a script
Launch Pad's per-phase `**Output:**` blocks were printed in no phase of any observed headless run, and a prompt rule asking for them changed nothing. Every Launch Pad phase now ends by running the new `scripts/launch-pad-phase.sh <id> <verdict>`, whose stdout is the phase line (`## Phase 2.5: FEASIBILITY — CAUTION`), so the line is in the transcript as a tool result whether or not the model writes it. The script holds the closed phase table and refuses an unknown id, an empty verdict or one over 160 characters (exit 2). `test-launch-pad-phase.sh` pins every line, checks that both `agents/launch-pad.md` and `commands/launch-pad.md` call every phase in the table, and carries mutation controls. Before and after counts: `docs/evidence/launch-pad-phase-lines.md`.
