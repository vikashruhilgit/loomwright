Host mode: with LOOMWRIGHT_HOST_MODE=1 no Loomwright hook writes into the session's repo (host-contract/02)
A host that runs agent sessions in an owner's own repo (Loomwright Studio first) can now set `LOOMWRIGHT_HOST_MODE=1`. A Studio probe had found one SDK session leaving `.claude/settings.local.json`, a `.supervisor/logs/<session>.jsonl` and a lifecycle heartbeat file behind, which silently changed the owner's later sessions. With the switch on, no hook creates or modifies any path in the working tree. Redirected state goes to `LOOMWRIGHT_HOST_STATE_DIR` when it is an absolute, existing directory outside the repo, in the same `.supervisor/` layout and the same JSONL line format. Without one (owner decision D1), the gate state — guard markers, the finalize-gate marker, and the `state.md`, session log and `.owner` seed those gates read — goes to `${TMPDIR:-/tmp}/loomwright-host-<uid>/<repo-hash>/` under `umask 077`, and every other hook write is skipped. One sourced resolver, `scripts/host-mode.sh`, serves every writer and every reader. The fail-CLOSED gates keep enforcing: the test-integrity guard reads its markers from the resolved dir and also protects that dir and `host-mode.sh`; the finalize-publish guard treats a run as live when either the agent-written repo `state.md` or the gate-dir copy says so, and a stale gate copy from an earlier run never hides a newer repo seed. Repo content mutations skip rather than redirect: the requirement-file stamp, the merged-brief moves, the review-drain dispatch and the `settings.local.json` OTEL write. With the switch off (unset, or any value but `1`) every hook is unchanged. `docs/HOOKS.md` §"Host mode" classifies every script `hooks.json` invokes, and the inline StopFailure leaf, as `redirects`, `skips` or `unaffected`, and lists the honest limits: host mode covers hooks only, so agent-written state still lands in the repo, and the projected `## Session` block lives only in the gate dir. New suite `scripts/test-host-mode.sh` fires every `hooks.json` leaf verbatim against throwaway repos in both host cases and off mode, with a mutation control.
