Version bumps go through one script: `scripts/bump-version.sh` folds `changelog.d/` fragments into ONE CHANGELOG entry and bumps both manifests atomically, so parallel PRs no longer collide on the version
Two open PRs that each hand-edited `plugin.json`, `marketplace.json` and `CHANGELOG.md` conflicted and could claim the same number (2026-09-27: #284 took v15.107.0 and the next PR was renumbered). A feature PR now carries only a `changelog.d/<slug>.md` fragment (an optional first-line bump directive requests patch, minor or major); distinct fragment files never conflict.
**`scripts/bump-version.sh [patch|minor|major] [--dry-run]`** refuses (exit 1, nothing written) when there is no fragment or the three files disagree, takes the highest level any fragment requests (default patch), folds every fragment in filename order into one `**vX.Y.Z — headline:** body` entry, and edits the loomwright `marketplace.json` version by a targeted one-line replacement, never a `jq .` round-trip, which would re-encode the stackpack / mysql-mcp description escapes. Order: back up the three files and fragments, render and self-verify, rename, delete the fragments, then run `validate-version.sh` + `check-doc-currency.sh`. Any failure, including a read-only `.claude-plugin/` directory or a failing validator, restores every file and fragment byte-identical. Test seam: `BUMP_VERSION_VALIDATORS`.
**Guard:** `check-doc-currency.sh` fails when the working-tree `plugin.json` version differs from the version at `git merge-base HEAD origin/main` while a fragment remains, which is a bump that skipped the script. A merely-behind branch stays green, an unresolvable `origin/main` skips with a visible note, and a hand bump with no fragment stays undetectable (stated in the header).
**Who bumps (P7):** in a sequential PR the author runs the script as the LAST commit; in a parallel wave the lanes write fragments only and the release lane bumps; an unfolded fragment merged without a bump folds into the next bump (`changelog.d/README.md`).
**Sweep:** lessons `[16ffd26d]` and `[a642885b]` superseded through `write-lessons.sh`; `AGENT_GUIDELINES.md` and `CLAUDE.md` gain a version-free pointer; six pending/parked requirements gain the bump amendment line. Tests: `scripts/test-bump-version.sh` (hermetic, incl. the read-only-directory, validator-failure, two-branch-merge, guard and `jq .` mutation controls). The `ci.yml` step for that test lands as its own follow-up PR, because a workflow edit makes `claude-code-action` skip its review.
