Written core contract for harness adapters (`docs/CORE_CONTRACT.md`) with a re-verified Cursor / Codex capability matrix
Until now the vendor-neutral core's contract existed only implicitly, spread across script headers and docs, so an adapter author for another harness had no single page saying what the core needs from a harness. `loomwright/docs/CORE_CONTRACT.md` (`core_contract_version: 1`, with an additive-keeps / removal-bumps compatibility policy) writes it down pointer-first. It covers the `.supervisor/` and `.agent/` file protocol (writer, lifecycle, tracked / gitignored / metadata-branch status and authority for each path), the CLI surface (the bimodal fail-CLOSED gate / fail-SAFE emitter convention and an index of the engine entry points, read from each script's own header), the five capability ports (run-a-subagent, run-in-background, isolate-a-workspace, react-to-an-event, deliver-instructions), and root resolution through `resolve-loomwright-root.sh`. Each port names its consuming seams, its Claude Code binding and a degraded fallback: shipped fallbacks name their seam, the rest are labelled proposed (not implemented), and the guarantees lost without hooks are named, including that a fail-CLOSED pre-tool guard has no explicit-invocation equivalent. The requirement's 2026-08-22 Cursor / Codex matrix was re-verified against official vendor pages fetched on 2026-10-11, with the URL and UTC fetch time recorded for each source and every unconfirmed cell marked UNVERIFIED. Changes found: Codex hooks are now on by default and need a trust review, Codex plugins can bundle hooks, and Cursor now documents its subagent-stop payload schema. That schema does not carry the inline report fields our validators read, so behavioural fidelity stays UNVERIFIED. `ARCHITECTURE_CONTRACTS.md` §"Portability" gains one pointer, and the coupling manifest gains the new doc's measured allowance with its reason. No script changes; moving the remaining direct readers of the harness root variable onto `LOOMWRIGHT_ROOT` is filed as a separate follow-up.
