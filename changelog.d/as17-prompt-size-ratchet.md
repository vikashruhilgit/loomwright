Size ceilings for every skill dir and command doc, not just agents
`scripts/check-token-budget.sh` now gates three tables in `loomwright/docs/prompt-token-budgets.json`, all fail-CLOSED in CI. `.agents[<stem>]` is unchanged. `.skills[<dir>]` measures every `*.md` under a skill dir, counted recursively, so a future `references/` subfolder is measured rather than skipped. `.commands[<stem>]` measures `loomwright/commands/<stem>.md`, and its dir is overridable through the new `TOKEN_BUDGET_COMMANDS_DIR`. A skill dir or command doc over its ceiling is a BREACH. A dir or doc with no entry, an orphaned or non-integer entry, and a missing or empty skills or commands dir are each an ERROR. Loose files at the skills root (`SKILLS_INDEX.md`, `SKILL_TEMPLATE.md`) are not skill dirs. Every skill dir and command doc starts at measured + ~10%. `ARCHITECTURE_CONTRACTS.md` §"Prompt Token Budgets" gains two mirror tables, which the gate checks the same way it checks the agent table: drifted budget or measured cells, missing rows and ghost rows all fail. Each table's parse is bounded by its own sub-heading, so a skill or command row can never read as an agent ghost row. Every budget `note` is now one line under 200 chars, and the raise rule says so: one-line reason in the `note`, history in `CHANGELOG.md` and the agent raise log. The figures that had lived only in a note were moved into the raise log first. Agent budgets and measured values are unchanged, and the JSON shrinks from 36898 to 11009 bytes. CLAUDE.md's new-command and new-skill steps now say to declare the ceiling. Evidence: `docs/evidence/automate-speed-17-prompt-size-ratchet.md`.
