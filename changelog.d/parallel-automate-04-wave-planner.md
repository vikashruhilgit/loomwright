New read-only wave planner `automate-helpers.sh plan-waves` + strict `## Depends on` / `## Touches` requirement sections + tracked `.agent/companions.json`
`plan-waves <runfile|dir|item-list> --max N [--root <checkout>]` turns a queue into waves of items that are safe to run together: dependency-ordered (an undeclared item depends on every earlier one), at most N per wave, no two whose companion-expanded `Touches` sets intersect (literal prefix), and an item with a missing or `unknown` `Touches` alone in its wave. An out-of-set dependency must be merged-done (a plain checked Queue row, or a done `## Status:` on any heading; an ABANDONED stamp wins) or its dependents print `blocked …`. It fails CLOSED — exit 1 with nothing on stdout — on an unknown dependency, a dependency cycle, a malformed companion table or a missing `jq`, writes nothing, and runs no git beyond `rev-parse --show-toplevel`. Nothing on the sequential path calls it; its only future caller is the `--parallel N>1` coordinator (parallel-automate item 05). `.agent/companions.json` (new, committed) names the files an edit drags along (a skill's `SKILLS_INDEX.md` row; an agent's token budget and contracts row; every doc-currency surface for a new agent/command/skill — copied from `scripts/check-doc-currency.sh`'s `FILES` array, with a test that fails on drift). The user-story-writing template (1.1.0) and Product Owner's persist step now emit both sections; the automate-loop skill (1.11.0) gains the §1.5 reference row. New test group `W.` in `test-automate-helpers.sh`, with two mutation controls (a missing `Touches` read as an empty set; the companion table removed).
