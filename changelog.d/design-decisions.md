Briefs record the chosen approach and the alternatives it beat
A Launch Pad brief can now carry an optional `## Design decisions` section between `## Task` and `## Acceptance Criteria`: one entry per approach trigger, each naming the decision, the chosen way, every rejected way with its reason, the evidence, the condition that would reopen it and a `status` of `confirmed` or `unconfirmed`. The new conditional Launch Pad Phase 2.7 APPROACH writes it only when a closed trigger fires: T1 a new dependency (a Phase 2.5 CAUTION row), T2 a new script or module (a File Impact Map CREATE row), or T3–T5 a new external integration, a cross-cutting mechanism or a hand-rolled platform feature named in the goal. A goal with no trigger prints `## Phase 2.7: APPROACH — no trigger` and gets no section. The protocol (candidates with "already in the repo" first, five unweighted yes/partial/no axes, three evidence sources with `WebSearch` only under `--discovery`) lives in the read-on-demand `skills/supervisor-readiness/design-decisions.md`, so the `launch-pad` agent budget is unchanged. On an axes tie or a T1 dependency Launch Pad asks once under the new human-only gate `LP-APPROACH` (`Keep <chosen>` · `Switch to <runner-up>` · `Decide later`); a run that cannot ask records the default pick `status: unconfirmed` and never aborts. The new conditional Plan Reviewer Criterion 23 verifies the entries without re-deciding them: a missing or unevidenced entry is a MEDIUM `approach_unjustified` issue, a T1 entry left `unconfirmed` makes the review NEEDS_HUMAN, and a CREATE path that reinvents an existing helper the entry never names is a HIGH `approach_reinvents` issue that FAILs the brief. The Red Team reviewer's first vector also asks whether a change reinvents something the platform or an existing module already provides. The worker is unchanged, and no house rule is written: the proposed advisory `/rules add` for new dependencies is in `docs/evidence/design-decisions.md` for the owner to run. Pinned by the new `loomwright/scripts/test-design-decisions.sh` and its fixtures under `loomwright/scripts/fixtures/design-decisions/`; `plan-reviewer` and the `supervisor-readiness` skill are re-baselined to measured + ~10%.
