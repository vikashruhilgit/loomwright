automate-lanes.sh and automate-trail.sh are split into sourced modules (move-only)
`scripts/automate-lanes.sh` and `scripts/automate-trail.sh` are now thin entry points that source one module per concern, by name, from `scripts/automate-lanes.d/` and `scripts/automate-trail.d/`, so a lane, wave or trail change touches a small file instead of one shared monolith. Each entry point's header carries a `# Modules (sourced in this order from …)` map naming the functions every module holds. Every subcommand, flag, output byte and exit code is unchanged: each entry point's bundle function, with its loader and source markers removed, reproduces the pre-split script byte for byte, and `lane-status` output from the same parent run file is byte-identical before and after apart from the fields that also change between two runs of the old script (the clock, the load average and the live keep-awake holders). A missing module fails closed naming the file; when `automate-lanes.sh` is sourced (by `automate-wave.sh` and the `guard-lane-wait-armed.sh` Stop hook) the source returns non-zero instead of exiting, so each caller's own fallback still runs. `test-automate-lanes.sh` and `test-automate-trail.sh` are runners that source their legs by name from `test-automate-lanes.d/` and `test-automate-trail.d/` and keep their totals (plus the new planted-violation legs below); the new `test-automate-lanes-modules.sh` and `test-automate-trail-modules.sh` prove the loaders against the real entry points. The gates that read test or script text now read the moved code too, each with a planted-violation leg: `test-no-pipefail-grep-q.sh` and `test-no-fixed-sleep-race.sh` scan `test-*.d/*.sh` (a part is held to its runner's `pipefail`), `test-wave-build.sh` W6d and the lanes test's fleet-closeout/wave-plan check read the modules, and `test-automate-loop-split.sh` §H reads the trail test's parts. The vendor-coupling allowances move with their references. Measurements and the list of non-move edits: `docs/evidence/as19-split-lanes-and-trail-scripts.md`.
