Backlog board feeds — `backlog --offline`, a Floor `backlog` surface, a `lane-status` pointer and a once-a-day SessionStart stamp nudge
`automate-helpers.sh backlog` gains `--offline`, accepted in every mode: it makes no `gh` call and no `right-size` call and reads exactly as both failing (`github: unverified`, the right-size column `unknown`), with no new key or state. Honest limit: an item whose only merge evidence is a merged PR is not counted `merged_unstamped` offline. The feeds that cannot wait on GitHub read the board through it, so every number comes from the one classifier and is never re-derived: `build-floor.sh` writes a `backlog` surface (state totals plus the items needing a decision), `lane-status` ends its plain views with one pointer line to `/backlog`, and the SessionStart startup arm prints at most one line a calendar day when any item reads `merged_unstamped` or `conflict` (opt out with `LOOMWRIGHT_BACKLOG_NUDGE=0`).
