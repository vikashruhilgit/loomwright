Squash-safe sweep of the worktrees and local branches the plugin left behind
New `automate-helpers.sh sweep [--apply] [--root <checkout>]` (delegated to `automate-trail.sh`) lists every leftover plugin-made linked worktree and local branch with a reason, and by default changes nothing. With `--apply` it removes only the `would-remove` items. An item qualifies under `closeout`'s own squash-safe rule: the branch's newest PR is MERGED and the local tip equals that PR's `headRefOid`. Worktrees go through `git worktree remove` (never `--force`), and only when the worktree is clean, holds no gitignored content beyond the salvage list and a short regenerable allowlist (`node_modules/`, `.venv/`, `dist/`, …; a `.env` or `.supervisor/state.md` keeps it, named in the reason — new read-only `worktree-salvage.sh --check-ignored`), is no live process's cwd (a path holding a byte `lsof` escapes, such as non-ASCII under a C locale, keeps it), and `worktree-salvage.sh --ignored` has copied and verified its gitignored runtime content (`.supervisor/logs/`, `.supervisor/postmortem/`, `.claude/settings.local.json`). `closeout` step 3a applies the same salvage gate for its own PR worktree, without the coverage refusal (`--allow-unsalvaged`). App-made, lane and unknown-origin worktrees are reported but never removed. The primary's current branch, the base branch and branches still checked out are never candidates. The command always exits 0 and prints one `sweep: summary — …` line last. `/automate --sweep [--apply]` runs only the sweep (no RESUME, no PICK, no run file). The owner's typed `--apply` is the authorization, and a source or `--resume` alongside it is refused. A run that reaches `## Status: done` appends one dry-run summary line to `## Progress`: the §6 Termination exit, `finalize-empty`, and `fleet-closeout`, which drops its old `sweep: unavailable` placeholder and records the line at the parent finalize, so a multi-wave run's line is the final wave's. Nothing runs `--apply` unattended. Evidence: `docs/evidence/af39a-sweep.md`.
