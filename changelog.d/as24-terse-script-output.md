Five plugin scripts print one summary line by default and keep their full output behind --verbose (automate-speed/24)
`classify-bot-review.sh` now prints `classify-bot-review: kept <K> of <N> (skipped_self <S>)`, and on each fail-safe path `kept 0 of 0 (reason <token>)`. `automate-lanes.sh lane-status` prints its header plus one line per lane; the wave PR, policy, steps, question, readiness and machine lines are now `--verbose` only, and `--watch` always shows the full view. `read-project-memory.sh` puts the verified count on its banner line (`— <E> verified`, or `— 0 verified (<reason>)`) and still prints one line per entry. `verify-provides.sh` prints `verify-provides: subtask <id> <verified|gap|unverifiable> — present <P>/<T>`, plus the gap or reason. `automate-helpers.sh plan-waves` accepts `--verbose` but prints the same bytes either way, because each of its modes already printed one line per wave, item or path. With `--verbose`, every script prints exactly what it printed before, and exact-bytes goldens captured from the pre-change scripts pin that. Mode flags keep their output: `lane-status --json`/`--inbox`/`--leaks`/`--resources`/`--tokens`, `plan-waves --touches`/`--explain`, and `verify-provides.sh --parse-only`/`--kind-table`. Every consumer that parses the old output now passes `--verbose`: the review-heal driver, the postmortem gather, the handoff digest, the Execute Manager, the Supervisor and worker `provides` gates, and the `--watch` loop. The consumer list is in `docs/evidence/as24-terse-script-output.md`. The saving is small and uneven. `lane-status` drops from about 28,000 to about 6,400 characters on a 24-lane run, and `verify-provides.sh` drops from about 1,300 bytes to 52. `read-project-memory.sh`'s default is 16 bytes longer than before, and `plan-waves` saves nothing.
